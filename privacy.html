Privacy Policy

Jordan OS Hub is a private app used only by its owner, Jordan Brodie, with his own Google accounts.

What it accesses

With Jordan's permission, it reads and updates his own Google Calendar events and reads his own Gmail messages, so they can be shown on his private dashboard and summarized for him.

How data is used and stored

  • Data is used only to provide Jordan's own calendar, email and planning views.
  • It is stored on Jordan's private server and private database, reachable only by him.
  • It is never sold, shared with other people, or used for advertising.

Google API data

Jordan OS Hub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
